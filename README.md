# বাজার দর (Bazar Dor) - Daily Commodity Prices Application

একটি আধুনিক ওয়েবসাইট যেখানে প্রতিদিনের বাজার দর, পণ্যের দামের ওঠানামা এবং ক্যাটাগরিভিত্তিক তথ্য সহজে দেখা যায়।

## 🚀 বৈশিষ্ট্যসমূহ (Features)
- **দৈনিক বাজার দর:** চাল, ডাল, তেল, সবজি এবং মসলাসহ প্রয়োজনীয় পণ্যের আপডেট মূল্য।
- **দামের পরিবর্তন ট্র্যাকিং:** গতকালের তুলনায় আজকের দাম বেড়েছে নাকি কমেছে তার লাইভ ইন্ডিকেটর।
- **ক্যাটাগরিভিত্তিক ফিল্টারিং:** প্রয়োজনীয় ক্যাটাগরি অনুসারে পণ্য সহজে খুঁজে বের করার সুবিধা।
- **ইউজার প্রফাইল ও অথেন্টিকেশন:** Sign in, Sign up এবং টোস্ট নোটিফিকেশন সিস্টেম।
- **রেসপনসিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসে ব্যবহারের উপযোগী।

## 🛠 প্রযুক্তি (Tech Stack)
- **Framework:** Next.js (App Router)
- **Language:** JavaScript / React
- **Styling:** Tailwind CSS & DaisyUI
- **Authentication:** Custom Auth Setup
